# Ajouter ou modifier votre fiche

## Si vous connaissez GitHub

1. Copiez `projets/_modele.yml` vers `projets/<votre-identifiant>.yml` (minuscules, chiffres et tirets).
2. Remplissez-le. Les commentaires du modèle expliquent chaque champ.
3. Ouvrez une demande de modification (pull request). Une vérification automatique vous dit, en français, ce qui ne va pas.
4. Pour mettre à jour : modifiez votre fiche et la date `mis_a_jour`.

## Si vous ne connaissez pas GitHub

Utilisez le formulaire « Nouvelle fiche » (onglet Issues). Le propriétaire du dépôt créera la fiche à votre place, avec votre accord.

## Règles

- Une personne modifie sa propre fiche. Les autres modifications sont relues par le propriétaire.
- Pseudos ou noms choisis par vous. **Jamais d'adresse électronique, de téléphone ou d'adresse postale.**
- Projet privé : écrivez `depot: prive`. Seuls le nom, l'étape et votre phrase s'affichent, jamais le code.
- Vous pouvez demander le retrait de votre fiche à tout moment ; il sera fait sans discussion.
- Pour mettre un projet volontairement en pause : `statut_force: en_pause` et, si vous voulez, `statut_force_jusqua: AAAA-MM-JJ`.
