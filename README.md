# Projets de la communauté Ouvre ta ferme

Ce dépôt recense les projets que des développeurs amateurs construisent autour d'[Ouvre ta ferme](https://ouvretaferme.org) : qui travaille sur quoi, où en est chaque projet, et lequel est actif. Le but est d'éviter que plusieurs d'entre nous refassent en double la même chose, et de repérer ce qu'on pourrait mettre en commun.

- **Participation volontaire** : vous décidez d'y figurer ou non, et de ce que vous montrez.
- **Activité mesurée** : pour un projet dont le code est public sur GitHub, le statut est calculé chaque lundi d'après le dernier commit (moins de 30 jours : actif ; 30 à 90 jours : en pause ; plus de 90 jours : sans activité). Pour les autres, il vient de la date de dernière relecture de la fiche.
- **Avancement** : une phrase écrite par vous. Aucun outil ne peut la deviner, merci de la mettre à jour quand elle change.
- **Aucune adresse électronique ni téléphone** dans les fiches.

Page web : voir l'onglet Pages du dépôt (adresse à indiquer ici une fois publiée).

Pour ajouter votre projet, lisez [CONTRIBUTING.md](CONTRIBUTING.md).
